AuraTab 技术支持与常见问题 · Support

1. 撤销第三方授权与清除数据 / Revoking Access & Deleting Data

  • 断开 Google 账号：在 Gmail、Google Drive 或待办设置弹窗中点击「退出连接」即可立即销毁当前会话内存令牌；如需彻底取消授权，请前往 Google 账号安全与权限管理 移除 AuraTab。
  • 清除扩展本地数据：在浏览器扩展管理页移除 AuraTab，或通过桌面「同步与备份」导出备份后在浏览器清理扩展存储空间。

2. 滴答清单 / TickTick 连接说明

扩展默认不连接任何开发方公共服务器。如需使用滴答清单 / TickTick 同步，可在待办设置中填写您自己部署的 AuraTab HTTPS 代理服务地址，或直接使用个人 Open API 访问令牌（令牌仅驻留当前会话内存）。

3. 问题反馈与联系渠道 / Contact

  • GitHub Issue 反馈：AuraTab 公开反馈。请勿附上口令或个人数据。
  • 商店支持通道：Microsoft Edge 外接程序商店 AuraTab 商品页「支持（Support）」标签页。
