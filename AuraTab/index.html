产品简介 / Product Overview

AuraTab 是一款坚持「本地优先（Local-First）」原则的浏览器新标签页工作台。它将浏览器空白新标签页替换为支持物理碰撞避让、底部常驻 Dock 栏、自适应明暗主题与自定义微插件沙箱的个人桌面，让常用网站、便签、天气、日历、专注计时与多源待办一屏可达。

AuraTab replaces your browser's new tab page with a fast, local-first personal dashboard featuring shortcut organization, folders, a persistent dock, focus mode, weather, calendar, Pomodoro timer, notes, isolated custom widgets, and end-to-end encrypted backup.

核心功能 / Key Capabilities

混排桌面与快捷收藏

支持快捷图标、文件夹与多种尺寸小组件自由混排，配合工具栏弹窗一键收藏当前网页。

端到端加密零知识同步

支持导出加密备份文件及私有 GitHub Gist / WebDAV 同步，所有数据均在本地通过 PBKDF2 + AES-256-GCM 加密。

安全隔离微插件工坊

支持 HTML/CSS/JS 自定义微插件开发，运行时隔离在独立的 plugin-frame.html 沙箱中，无扩展权限与外网权限。

按需连接 Google Workspace

用户可选择性授权连接 Google Tasks、Gmail（只读）与 Google Drive（仅文件元数据只读），完全在客户端会话内存运行。

Google 用户数据使用声明 / Google API Data Usage

AuraTab 没有开发方后端服务器，也不会收集或上传任何用户数据。仅当用户主动点击「Sign in with Google」时，扩展通过浏览器原生 chrome.identity.launchWebAuthFlow 获取会话级 OAuth 访问令牌（仅驻留内存，关闭标签页或退出登录即销毁），并直接向 Google 官方接口请求：

  • https://www.googleapis.com/auth/tasks — 同步、创建、完成与管理用户的 Google Tasks 待办清单；
  • https://www.googleapis.com/auth/gmail.readonly — 仅用于在新标签页组件中向用户展示收件箱未读数、发件人、主题与正文；
  • https://www.googleapis.com/auth/drive.metadata.readonly — 仅用于列示并检索文件名称、修改时间与在线打开链接，不下载文件正文。

AuraTab 对 Google API 数据的使用严格遵守 Google API Services User Data Policy 及 Limited Use（有限使用） 规定。详见完整 隐私政策（Privacy Policy）。
