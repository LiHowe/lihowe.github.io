AuraTab 新标签页隐私政策 · Privacy Policy

生效日期：2026-11-18 · 适用版本：1.4.4 · 项目主页：https://lihowe.github.io/AuraTab/

1. 本地优先与零追踪承诺 / Local-First & Zero Tracking

AuraTab 是一款坚持本地优先（Local-First）原则的浏览器新标签页工作台。我们不部署任何第三方行为分析、广告追踪器或后台遥测上报服务，不会收集、出售或共享您的浏览历史与个人资料。

AuraTab is a local-first browser new tab workspace. We do not deploy analytics trackers, ad networks, or background telemetry, and we never sell, rent, or share your browsing history or personal data.

2. 设备本地存储与扩展权限 / Local Data & Browser Permissions

  • 本地桌面数据：您的快捷方式、文件夹、便签、本地待办、组件布局、自定义微插件代码及外观设置均保存在当前浏览器的 IndexedDB 与本地存储（localStorage）中。
  • activeTab：仅在您主动点击浏览器工具栏上的 AuraTab 扩展图标时，临时读取当前活动标签页的标题、网址与站点图标，用于供您确认添加到指定主页工作区；绝不在后台静默采集任何浏览页面。
  • bookmarks：仅用于在新标签页的「收藏夹管理」工作台与收藏夹桌面组件中读取、实时同步浏览器原生收藏夹，并在您主动触发编辑、排序、移动或删除时将变更写回浏览器收藏夹；所有收藏夹数据仅在您的本地浏览器处理，绝不上传至开发者或第三方服务器。
  • search：当您在新标签页搜索框选择「浏览器默认」并提交非网址检索词时，通过浏览器原生接口将搜索词交由浏览器默认搜索引擎处理，绝不篡改浏览器默认搜索设置。
  • favicon：扩展模式下通过浏览器本地缓存接口（_favicon/）显示网站图标，避免将您收藏的网址逐一发送到第三方图标服务器。仅当您手动指定外部图片地址时，浏览器才会向对应图片源发起加载请求。
  • identity：仅在您主动点击连接 Google 账号或自己配置的滴答代理服务时，拉起浏览器原生 OAuth 2.0 授权流程，访问令牌仅驻留于当前会话内存中。
  • 独立插件沙箱（sandbox: plugin-frame.html）：您编写或导入的自定义微插件在无扩展 API 权限、无网络访问权限的隔离沙箱页面内运行。

Shortcuts, folders, notes, local tasks, layouts, custom widgets, and appearance preferences are stored locally in IndexedDB and browser localStorage. activeTab is used solely upon your click on the toolbar popup to read the active tab's title, URL, and icon. bookmarks is used solely on-device to display, synchronize, and manage your browser bookmarks (create, edit, sort, move, delete) inside AuraTab's Bookmark Manager without uploading bookmark data to any server. search delegates search queries to your browser's default search provider without altering settings. favicon reads cached site icons locally. identity initiates user-triggered OAuth flows, keeping tokens strictly in memory. Custom widgets run inside an isolated plugin-frame.html sandbox without extension APIs or network access.

3. 联网工具组件 / Connected Utility Widgets

  • 天气预报：仅在您主动刷新定位或检索城市时，向 Open-Meteo（api.open-meteo.com / geocoding-api.open-meteo.com）发送所选城市名称或经纬度坐标以获取气象数据，结果仅缓存在本地浏览器。
  • 参考汇率：汇率组件向 ExchangeRate-API 公开接口（open.er-api.com）请求人民币基准参考汇率并在本地缓存。
  • 在线壁纸与外部图片：当您选用在线壁纸或自定义图片 URL 时，您的浏览器会向对应的图片托管服务发起常规网络请求。

4. Google Workspace 数据访问与有限使用政策 / Google API Services User Data Policy

  • 纯客户端直连与按需授权：仅在您主动点击“Sign in with Google”后，AuraTab 才会通过浏览器原生 OAuth 申请对应工作区权限范围：
    • https://www.googleapis.com/auth/tasks：同步、创建、完成与删除您主动确认的 Google Tasks 待办任务；
    • https://www.googleapis.com/auth/gmail.readonly：只读获取收件箱未读数量、邮件发件人、主题、摘要与正文，仅用于在您的新标签页桌面卡片及展开浮窗内展示；
    • https://www.googleapis.com/auth/drive.metadata.readonly：仅读取云端文件名称、类型、所有者、修改时间与在线打开链接等元数据，不下载或存储您的 Drive 文件正文。
  • 纯内存令牌，零开发方服务器留存：Google OAuth 访问令牌仅保存在当前标签页会话内存中，绝不写入硬盘或发送至任何开发方服务器，退出登录或关闭页面后立即销毁。
  • Limited Use 合规声明：AuraTab 对从 Google API 获取的用户数据的使用与传输，严格遵守 Google API 服务用户数据政策（Google API Services User Data Policy） 及其中“有限使用（Limited Use）”要求。Google 用户数据仅用于面向用户展示与用户主动触发的操作，绝不用于广告投放、画像分析、数据出售或训练通用人工智能/机器学习模型。

AuraTab's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. OAuth access tokens remain strictly in active session memory and are never transmitted to or stored on developer servers.

5. 自建滴答清单 / TickTick 服务连接

扩展模式下，滴答清单 / TickTick 集成不依赖开发方公共服务器，仅连接您在待办设置中显式保存的个人 HTTPS 代理服务地址或您输入的个人 Open API 访问令牌（令牌仅保存于当前会话内存）。请仅使用由您自己部署或完全信任的 HTTPS 服务。

6. 端到端加密同步与数据清除 / Encrypted Backup & Data Deletion

使用加密备份、私有 GitHub Gist（api.github.com）或个人 WebDAV 同步时，所有桌面数据均在离开设备前于本地通过 Web Crypto API（PBKDF2-SHA256 + AES-256-GCM）完成加密，加密口令永不上传。您可随时在组件内断开账户连接、前往 Google 账号权限管理 撤销授权、在浏览器中卸载 AuraTab 以清除全部本地存储数据，或手动删除您 Gist / WebDAV 中的密文文件。

开启 WebDAV 自动同步时，AuraTab 仅向您配置的服务器发送桌面密文及该服务器需要的认证信息。加密主口令加密存放在当前浏览器，关闭自动同步时删除该口令副本。

Automatic WebDAV sync sends encrypted workspace data and server authentication only to the configured server. The encryption passphrase is stored encrypted in the current browser. Turning off automatic sync removes the saved passphrase.

7. AI 创建微插件 / AI Plugin Creation

使用 AI 创建时，AuraTab 将你输入的需求、所选模型和上一版 AI 设计（仅在调整时）发送到你填写的 HTTPS API 服务。API Key 仅在当前标签页内存中保留，并置于发往该服务的认证头。服务地址和模型保存在本机，AI 连接设置与 Key 不随插件、备份或同步发送。外部服务的数据处理及费用适用该服务的条款。

AI plugin creation sends your prompt, selected model, and previous AI draft during revisions to your configured HTTPS API. The API key stays in the current tab's memory and is sent in the Authorization header. The service address and model are saved locally. Connection settings and keys are excluded from plugins, backups, and sync.

8. 快捷方式网页查看 / Viewing Shortcut Websites

当您选择在弹窗、侧边栏、小窗或新标签页打开快捷方式时，浏览器直接访问所选网站。扩展通过 sidePanel 打开浏览器侧边栏，使用 storage.session 将选中的网址交给该窗口的侧边栏。此会话记录在浏览器退出后清除。

Opening a shortcut in the viewer or another browser window sends the selected website request directly from the browser. The extension uses Side Panel and session storage to pass the selected URL to the sidebar in that browser window. The session record clears when the browser closes.
