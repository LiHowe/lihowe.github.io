AuraTab 新标签页隐私政策 · Privacy Policy

生效日期：2026-11-19 · 适用版本：1.5.1 · 项目主页：https://lihowe.github.io/AuraTab/

1. 本地优先与零追踪承诺 / Local-First & Zero Tracking

AuraTab 默认在当前设备保存桌面。联网组件向下文列出的服务请求数据，启用同步时会将相应内容传给您选择的服务。我们不出售个人数据，也不使用广告追踪、行为分析或后台遥测。

AuraTab saves your workspace on this device by default. Connected widgets contact the services described below. When you use sync, the selected service receives the corresponding data. We do not sell personal data or use advertising trackers, behavioral analytics, or background telemetry.

2. 设备本地存储与扩展权限 / Local Data & Browser Permissions

  • 本地桌面数据：您的快捷方式、文件夹、便签、本地待办、组件布局、自定义微插件代码及外观设置均保存在当前浏览器的 IndexedDB 与本地存储（localStorage）中。
  • activeTab：仅在您主动点击浏览器工具栏上的 AuraTab 扩展图标时，临时读取当前活动标签页的标题、网址与站点图标，用于供您确认添加到指定主页工作区；绝不在后台静默采集任何浏览页面。
  • bookmarks：用于本地检索、查看和管理浏览器收藏夹。编辑、移动或删除会写回浏览器。您选择导入桌面的书签会成为快捷方式，随您选择的桌面备份或同步方式处理。
  • search：当您在新标签页搜索框选择「浏览器默认」并提交非网址检索词时，通过浏览器原生接口将搜索词交由浏览器默认搜索引擎处理，绝不篡改浏览器默认搜索设置。
  • favicon：扩展模式下通过浏览器本地缓存接口（_favicon/）显示网站图标，避免将您收藏的网址逐一发送到第三方图标服务器。仅当您手动指定外部图片地址时，浏览器才会向对应图片源发起加载请求。
  • identity：仅在您主动点击连接 Google 账号或自己配置的滴答代理服务时，拉起浏览器原生 OAuth 2.0 授权流程，访问令牌仅驻留于当前会话内存中。
  • storage：天气预报缓存在当前浏览器会话。您在同步备份中心上传或恢复桌面配置时，AuraTab 也会使用浏览器账号的同步存储，见第 6 节。
  • 独立插件沙箱（sandbox: plugin-frame.html）：您编写或导入的自定义微插件在无扩展 API 权限、无网络访问权限的隔离沙箱页面内运行。

Desktop items and settings are stored locally. Clicking the toolbar button lets AuraTab read the active tab’s title, URL and icon. You can search and manage bookmarks locally. Bookmarks you import into the desktop become shortcuts and can be backed up or synced as described in section 6. Search uses the provider you select. Your browser supplies cached site icons, runs sign-in when requested, and provides session storage for weather and account storage for optional workspace sync. Custom widgets run in an isolated sandbox without extension APIs or network access.

3. 联网工具组件 / Connected Utility Widgets

  • 天气预报：搜索城市时，Open-Meteo 收到您输入的城市名。天气组件在加载、手动刷新和按设置的间隔更新时，将所选城市的经纬度发送给 Open-Meteo 获取预报，默认每小时更新一次。
  • 日历订阅：添加在线日历或刷新订阅时，AuraTab 访问您提供的日历网址，必要时请求访问该主机的权限。应用会在本地缓存日程以便离线查看，删除订阅会清除其缓存。在线更新中国节假日时，仅按年份向 jsDelivr 请求公开节假日表。
  • 参考汇率：汇率组件向 ExchangeRate-API 公开接口（open.er-api.com）请求人民币基准参考汇率并在本地缓存。
  • 在线壁纸与外部图片：当您选用在线壁纸或自定义图片 URL 时，您的浏览器会向对应的图片托管服务发起常规网络请求。

Weather searches send the city name to Open-Meteo. Loading or refreshing the widget sends the selected city’s coordinates, including scheduled updates (hourly by default). Calendar subscriptions fetch events from the URL you supply and may ask for access to that host. Removing a subscription clears its local event cache. Public holiday updates request data by year from jsDelivr. ExchangeRate-API provides reference rates, and external image hosts receive ordinary image requests.

4. Google Workspace 数据访问与有限使用政策 / Google API Services User Data Policy

  • 纯客户端直连与按需授权：仅在您主动点击“Sign in with Google”后，AuraTab 才会通过浏览器原生 OAuth 申请对应工作区权限范围：
    • openid、email、profile：从 Google 获取当前账号的邮箱、显示名称与头像，用于显示已连接的账号；
    • https://www.googleapis.com/auth/tasks：同步、创建、完成与删除您主动确认的 Google Tasks 待办任务；
    • https://www.googleapis.com/auth/gmail.readonly：只读获取收件箱未读数量、邮件发件人、主题、摘要与正文，仅用于在您的新标签页桌面卡片及展开浮窗内展示；
    • https://www.googleapis.com/auth/drive.metadata.readonly：仅读取云端文件名称、类型、所有者、修改时间与在线打开链接等元数据，不下载或存储您的 Drive 文件正文。
  • 纯内存令牌，零开发方服务器留存：Google OAuth 访问令牌仅保存在当前标签页会话内存中，绝不写入硬盘或发送至任何开发方服务器，退出登录或关闭页面后立即销毁。
  • Limited Use 合规声明：AuraTab 对从 Google API 获取的用户数据的使用与传输，严格遵守 Google API 服务用户数据政策（Google API Services User Data Policy） 及其中“有限使用（Limited Use）”要求。Google 用户数据仅用于面向用户展示与用户主动触发的操作，绝不用于广告投放、画像分析、数据出售或训练通用人工智能/机器学习模型。

Signing in retrieves your Google account’s email, display name and profile photo. Google Tasks access lets you view and manage tasks. Read-only Gmail access shows unread counts and message details, including bodies. Drive access shows file metadata and links. AuraTab's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. OAuth access tokens remain in active session memory.

5. 自建滴答清单 / TickTick 服务连接

您连接滴答清单 / TickTick 后，AuraTab 通过您在待办设置中保存的 HTTPS 代理请求项目和任务，并发送您创建、完成或删除任务所需的数据。访问令牌只保存在当前页面的内存中，随请求发送给您指定的代理；代理可读取令牌和任务数据。

Connecting TickTick lets the HTTPS proxy you configure receive the access token and task data to show projects and manage tasks. The extension keeps the token in this tab’s memory.

6. 备份、同步与数据清除 / Backup, Sync & Data Deletion

在同步备份中心选择上传到浏览器账号后，AuraTab 将工作区、快捷方式标题和网址、文件夹、Dock、外观与搜索设置、天气城市及坐标、自选币种和纪念日配置写入浏览器同步存储。浏览器启用账号同步时，这些配置可同步至该账号的其他设备。浏览器账号同步由浏览器提供，加密主口令仅用于下述加密备份。

使用加密备份、私有 GitHub Gist（api.github.com）或个人 WebDAV 同步时，所有桌面数据均在离开设备前于本地通过 Web Crypto API（PBKDF2-SHA256 + AES-256-GCM）完成加密，加密口令永不上传。您可随时在组件内断开账户连接、前往 Google 账号权限管理 撤销授权、在浏览器中卸载 AuraTab 以清除全部本地存储数据，或手动删除您 Gist / WebDAV 中的密文文件。

开启 WebDAV 自动同步时，AuraTab 会请求访问您配置的服务器，向它发送桌面密文及该服务器需要的认证信息。加密主口令加密存放在当前浏览器，关闭自动同步时删除该口令副本。

When you upload to your browser account, synced storage receives workspaces, shortcut titles and URLs, folders, dock layout, appearance and search settings, weather cities and coordinates, currencies and anniversary settings. Your browser can sync these to other devices on the same account. Gist and WebDAV backups use a separate passphrase and are encrypted on the device. Automatic WebDAV sync requests access to your configured server and sends it the encrypted backup and server authentication. Turning off automatic sync removes the locally saved passphrase. You can delete encrypted files at the chosen service.

7. AI 创建微插件 / AI Plugin Creation

使用 AI 创建时，AuraTab 将你输入的需求、所选模型和上一版 AI 设计（仅在调整时）发送到你填写的 HTTPS API 服务。API Key 仅在当前标签页内存中保留，并置于发往该服务的认证头。服务地址和模型保存在本机，AI 连接设置与 Key 不随插件、备份或同步发送。外部服务的数据处理及费用适用该服务的条款。

AI plugin creation sends your prompt, selected model, and previous AI draft during revisions to your configured HTTPS API. The API key stays in the current tab's memory and is sent in the Authorization header. The service address and model are saved locally. Connection settings and keys are excluded from plugins, backups, and sync.

8. 快捷方式网页查看 / Viewing Shortcut Websites

当您选择在弹窗、分屏或新标签页打开快捷方式时，浏览器直接访问所选网站。扩展不改写这些网页的响应头，不读取或上传其内容。

When you open a shortcut in a popup, split view, or new tab, the browser visits the selected website directly. The extension does not modify these response headers or read or upload the pages' contents.
